## ERP-Rassvet (актуальный стек)

Проект полностью переведен на новый стек:

- **Backend:** Python + FastAPI + SQLAlchemy + Pydantic
- **Frontend:** Vue 3 (Vite) + Tailwind CSS
- **База данных:** SQLite (WAL mode)
- **Авторизация:** JWT (Bearer token)

---

## Структура проекта

- `backend/` — API, модели БД, бизнес-логика, сидирование данных
- `frontend/` — SPA-интерфейс на Vue 3

---

## Что реализовано

- Полная русская локализация UI и API-ответов.
- Роли: **Админ**, **Директор**, **Волонтер**, **Педагог**.
- Вход с блокировкой по аккаунту и по роли.
- Автогенерация логина по формуле `familia_ii` (пример: `tymchenko_av`).
- Сайдбар с 4 вкладками:
  - **Администрирование**
  - **Люди**
  - **Игровые профиля**
  - **Игры**
- Подвкладки в модуле «Администрирование»:
  - **Управление доступом** (аккаунты, блокировки, сброс пароля на `pas123` с обязательной сменой),
  - **Управление ролями** (CRUD ролей + матрица прав Read/Write/Hidden),
  - **Управление вкладками** (CRUD вкладок UI + привязка к представлениям БД).
- Единая карточка пользователя (`/profile/:entityType/:id`):
  - фото + ФИО,
  - кликабельные связи родственников,
  - игровая история,
  - ролевое отображение данных (read-only для волонтера).
- Массовые операции в разделе «Люди» (обернуты в транзакции).
- Быстрый режим начисления в «Игровые профиля».
- Расчет золота: `floor(цена / 2)`.
- Транзакционные операции для изменения связей родственников.
- Backend и frontend запускаются на `0.0.0.0` (доступ из локальной сети).

## Инструкция по запуску

### Требования

- Python 3.10+
- Node.js 20+
- npm

### 1) Запуск backend (терминал №1)

```bash
cd backend
python3 -m pip install -r requirements.txt
python3 main.py
```

После запуска:
- API: `http://127.0.0.1:8000`
- OpenAPI: `http://127.0.0.1:8000/docs`

### 2) Запуск frontend (терминал №2)

```bash
cd frontend
npm install
npm run dev
```

После запуска:
- Web UI: `http://127.0.0.1:5173`

### 3) Доступ из локальной сети

Так как сервисы слушают `0.0.0.0`, приложение открывается с других устройств по IP машины:

- `http://<LAN_IP>:5173`

## Основные API-маршруты

- `POST /api/auth/login` — вход
- `GET /api/auth/me` — текущий пользователь
- `POST /api/auth/change-password` — смена пароля
- `GET /api/ui/navigation` — вкладки интерфейса по RBAC
- `GET /api/admin/bootstrap` — данные админ-модуля
- `POST /api/admin/accounts/{id}/reset-password` — сброс пароля
- `POST /api/admin/roles/{id}/permissions` — права роли по вкладкам
- `GET /api/people/bootstrap` — таблицы раздела «Люди»
- `POST /api/people/bulk-delete` — массовое удаление в транзакции
- `GET /api/game-profiles/bootstrap` — игровые профили + быстрый режим
- `GET /api/games/bootstrap` — журнал игр + форма создания
- `POST /api/games/preview-gold` — предпросмотр расчета золота
- `POST /api/games` — создание игрового лога
